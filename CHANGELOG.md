## [1.0.0] - 2026-05-21

### Added
- Initial release of Antigravity 2.0 Nix flake
- Support for Linux x86_64 platform
- Automatic weekly update workflow via GitHub Actions
- SHA-512 checksum verification for security
- Comprehensive documentation (README, CONTRIBUTING, etc.)
- GitHub issue and PR templates
- Update script for manual version updates
- Multi-platform architecture (Linux, macOS, x64, ARM64)
- Development shell with Antigravity pre-installed
- Flake apps for easy execution

### Security
- Implemented SHA-512 checksum verification for all downloads
- Using official Google Cloud Storage sources only
