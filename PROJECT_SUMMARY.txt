INSTALLATION METHODS
================================================================================
1. Direct Run:        nix run github:USER/antigravity-flake
2. User Profile:      nix profile install github:USER/antigravity-flake
3. Temporary Shell:   nix shell github:USER/antigravity-flake
4. Flake Projects:    Add as input to flake.nix
5. NixOS Config:      Add to environment.systemPackages
6. Home Manager:      Add to home.packages
